# 导师：按标准写，不按感觉写

## 你手上只有这些

- `<work>/runs/<N>/task.md`：题目与用户硬约束（照抄的，不许转述）
- `<work>/rubric.json`：教授给的判据
- 素材文件

**你不能改 `rubric.json`。** 觉得某条判据不合理，去找教授问它的初衷；改尺子等于自己给自己出题，这条路已经废过一次。

## 第一步：把判据翻译成句子

写稿之前先填这张表，填不出来说明你还没读懂判据：

| 维度 | 这条判据要求稿里出现的那一句 | 它会落在哪一节 |
|---|---|---|
| d1（权重） | 一句具体的话，带路径/数字/引文/命令 | §二 |
| d2（权重） | 同上 | §三 |

**两维共用同一句 = 有一维没做到。** 一句能同时满足两条判据，通常说明其中一条写得太虚。

写不出来就去问教授，不要在稿里塞「深度」「逻辑」「价值」这类词来凑。

## 第二步：先造证据句，再连成文

顺序反了就会变成「先写一段漂亮话，再想办法证明它」——那是被打回最多的一种稿。

1. 按权重从高到低，把上表每一行写成一句具体的话（带路径、数字、引文、命令）。
2. 每句打个 tag 标它服务哪一维。
3. **最后**才做通顺化。通顺化只许调整连接与删冗余，不许动证据本身。

## 第三步：自评（`score-v1.json`）

只给四档：**0 / 4 / 7 / 10**。不许给 8、9——那是在回避判断。

```json
{
  "round": 1,
  "total": 92.5,
  "dims": [
    { "id": "d1", "score": 10, "quote": "从 draft-v1.md 逐字抄一段 ≥12 字", "deductions": [] },
    { "id": "d2", "score": 7,  "quote": "逐字抄一段 ≥12 字",
      "deductions": [
        { "fix": "把 draft-v1.md:63 的「这个数字大约是二十八万条」改成「281,023 行（精华企业库.csv，185.1 MB，38 列）」" }
      ] }
  ]
}
```

三条硬规矩：

1. **`quote` 必须逐字出现在那版稿里**（≥12 字）。抄不出来 = 你其实没读到那一维。
2. **不满分就必须有 `deductions`**，每条 `fix` 写成 `把 draft-vX.md:NN 的「原文≥12字」改成「新句」`。写「深度不足」「可以更清楚」= 你只知道不满意，不知道改哪句。
3. **`total` 按 rubric 权重重算**，差 0.001 就是算错。

一维从 10 掉到 7，总分 = 100 − 3w/10（w=30 → 91，w=20 → 94，w=15 → 95.5，w=10 → 97）。**95 不是 100**：高权重维度不能掉档，低权重维度可以。

## 第四步：改（`draft-v2.md`）

- 只动 `deductions` 点到的句子。
- **至少删掉一处。** 只加不减会让稿子越长越像 AI，也让你不敢承认原来那句是废话。
- 改完重新填 `score-v2.json`，quote 从 **v2** 里抄。

## 第五步：请独立的人判一次

找**另一个 context 干净的人**（通常是一个不带你自评分的 subagent），只给他题目、rubric 和 v2 稿，让他逐维去稿里找那句 quote：

- 找不到 → 那一维是空的，回第一步
- 找到但意思对不上 → 判据与内容错位，去找教授问初衷
- 他给的分高于自评 → 先回看自己哪一维判过严，写不出理由就维持低分

**别自己给自己判分再当外部记录。** 那枚章盖了也没有意义，而且一眼就能看出来。

## 第六步：到 95 就交

四条红线不看分数，命中一条就不许交：

| 红线 | 表现 |
|---|---|
| 数字编造 | 写了素材里没有的数，或把估算写成实测 |
| 拿立场当事实 | 「性价比高」「行业领先」这类没有对象的判断句 |
| 两份材料打架 | 一页式说免费、口播说收费；同一件事两个数 |
| 答应做不到的 | 承诺没有的能力、没有的团队、没有的交付时间 |

过了红线且 ≥95：**直接把成品贴给用户**。不写 `final/` 目录，不跑任何命令，不把「我自评 96」当结尾——用户要的是成品，不是分数。

## 怎么算「超过 95」

95 是「每条判据都满足」，再往上只有一种加法：**判据没写、但用户下一秒真的需要的东西。**

| 类型 | 例子 |
|---|---|
| 执行路径 | 「下周一你先做这三步，第一步是拍那张证」 |
| 可复用件 | 「这段话术你可以直接复制发给对方」 |
| 预答 | 「他会追问 X，答案在第三节最后一句」 |

要求：这东西要在稿里真的存在，且能说清「他为什么没想到」。

**不许为了凑增量加废话。** 对下一步没用的增量不算加分，算噪音。

## 卡住了：交 blocked.md，不交稿

三轮还没到 95，写 `runs/<N>/blocked.md`：

```markdown
# 卡在 d2（数字可查）
当前总分：92.5
缺什么：素材里没有 2024 年的产能数字，我不能编
需要你给什么：一份含产能的文件，或一句「这个数可以不写」
你不给时我停在：draft-v3.md
```

**这是唯一被允许的「未完成交付」**，而且它不是交付——是问人。

## 不要做的四件事

1. **不要改 rubric。** 改了旧分立刻作废。
2. **不要自己扮演外部判分人。** 要真找另一个 context 干净的人。
3. **不要在稿里写「如上所述」「综上所述」充数。** 判据抽不出来，只会拉低机制维。
4. **不要先写稿再回头把稿的特征写成判据。** 那是这套流程存在的理由，教授的职责正是防这个。
